# 共同 Markdown 契约

- 输出一个与交付物一致的二级标题；正文使用三级标题组织结构。除 `outline` 与 `bibliography` 外，列出的每个三级标题后必须至少有一个完整分析段落。
- 不输出“Retrieved Sources”、参考文献清单、URL 列表或 BibTeX 正文。
- 事实性段落必须使用当前证据池允许的 `\\cite{key}`；不得伪造论文、作者、年份、方法、实验设置或结果。
- 优先依据本地全文片段。只有题名或摘要时，只能做高层研究定位，不能断言具体机制、数值提升或限制。
- 各段必须承担不同作用，不重复同一段落、同一开头或“证据不足”套话。
- 正文不是大纲：不得只输出标题、项目符号、论文题目串或“待补充”等占位语。非短格式文稿至少应有三个实质性段落，并在交付前检查每个标题下均有正文。
- 使用用户语言，保持普通学术写作的自然段落；不要暴露内部字段、工具名或思考过程。
